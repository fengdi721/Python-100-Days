## 5–10 分钟面试热身

先预测三个结果。Python round 在恰好位于两个整数中间时如何选择？比较 PHP 默认 round 和 JavaScript Math.round 对正负中点的处理；如果要计算货币金额，为什么不应直接依赖二进制浮点数的默认舍入？

```python
print(round(2.5))
print(round(3.5))
print(round(-2.5))
```

验收：能说明 Python 对中点采用 ties-to-even（取最近偶数），所以结果依次为 2、4、-2；跨语言移植时先确认舍入模式，金额计算通常使用 Decimal 或以最小货币单位存储整数。
