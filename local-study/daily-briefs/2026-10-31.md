## 5–10 分钟面试热身

先预测两个解包结果。星号目标拿到的是什么类型？为什么 Python 能把它放在中间，而 JavaScript 的数组 rest 元素必须位于末尾？再试着解释当可分配元素不足时会发生什么。

```python
first, *middle, last = ["head", "red", "blue", "tail"]
print(first, middle, last)

first, *middle, last = ["head", "tail"]
print(first, middle, last)
```

验收：能说明星号目标会收集零个或多个中间元素并生成一个 list；每次解包最多有一个星号目标，未星号的目标仍需有足够元素。
