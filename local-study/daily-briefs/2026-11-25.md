## 5–10 分钟面试热身

先预测两行输出分别能保证什么：

```python
tags = ["php", "python", "php", "node"]
print(list(set(tags)))
print(list(dict.fromkeys(tags)))
```

说明第一行能去重，但不能保证按输入顺序排列；第二行利用字典保留插入顺序，得到稳定去重结果。对照 JavaScript `Set` 保留插入顺序的行为，并指出不要在测试中断言 `set` 的具体遍历次序。
