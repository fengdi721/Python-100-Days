## 5–10 分钟面试热身

先预测会打印什么，以及最终字典内容：

```python
cache = {"user:42": "cached"}

def make_default():
    print("building default")
    return "new value"

result = cache.setdefault("user:42", make_default())
print(result, cache)
```

解释为什么键已经存在，`make_default()` 仍会运行：Python 会先求值函数实参，再调用 `setdefault`。说明若默认值构造有成本或副作用，如何用显式 `if key not in cache` 延迟创建；PHP 和 Node.js 的普通函数实参也会在调用前求值。
