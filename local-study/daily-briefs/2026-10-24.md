## 5–10 分钟面试热身

先预测两次调用分别会输出什么，再解释原因。为什么 Python 中可变默认参数容易导致跨调用共享状态？如何改写以便每次调用都获得独立列表？对照 PHP 或 JavaScript 时，重点说明默认值何时创建、是否可能复用对象。

```python
def add_tag(tag, tags=[]):
    tags.append(tag)
    return tags

print(add_tag("python"))
print(add_tag("php"))
```

验收：能解释默认参数在函数定义时求值、两次调用复用同一列表，并能写出用 `None` 作为哨兵、在函数体内新建列表的修正版。
