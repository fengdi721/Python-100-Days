## 5–10 分钟面试热身

先预测输出，并说明为什么 `x` 在链式比较中只需求值一次。然后把 `0 < x <= 10` 写成不依赖链式比较的等价布尔表达式；与 JavaScript/PHP 中常见的 `&&` 写法比较。

```python
for x in (0, 5, 10):
    print(x, 0 < x <= 10)

print(1 < 2 < 3)
print(1 < 2 > 3)
```

验收：能说明链式比较相当于相邻比较之间用 `and` 连接，但中间表达式只求值一次；指出它不是把比较结果再与下一个数值比较。
