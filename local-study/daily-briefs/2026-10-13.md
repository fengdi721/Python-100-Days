## 5–10 分钟面试热身

先预测输出并解释：键已存在时，`setdefault` 的默认值表达式还会不会执行？`append` 修改的是哪个列表？对比 JavaScript 的 `??=`，说明右侧表达式何时求值。

```python
events = []

def make_default():
    events.append("created")
    return []

cache = {"users": []}
cache.setdefault("users", make_default()).append("Python")
print(events, cache)
```

验收：能说明 Python 会先求值函数实参，再调用 `setdefault`；默认表达式的副作用会发生，但已有键对应的列表仍是被追加的对象。
