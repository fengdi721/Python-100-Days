## 5–10 分钟面试热身

先预测两次打印的键顺序。给已有键赋新值会改变它的位置吗？删除后重新插入呢？再用 PHP 关联数组和 JavaScript 普通对象的键顺序规则作比较。

```python
languages = {"PHP": "backend", "Node.js": "runtime", "Python": "language"}
languages["PHP"] = "server-side"
print(list(languages))

del languages["Node.js"]
languages["Node.js"] = "runtime"
print(list(languages))
```

验收：能解释 Python 字典保留插入顺序、更新现有键不改变其位置，而删除再插入会出现在末尾；说明 JavaScript 对整数索引键还有单独的枚举顺序规则。
