## 5–10 分钟面试热身

先预测两次打印的结果。列表推导式里的 n 会不会覆盖外层的 n？普通 for 循环的变量 i 离开循环后还能访问吗？对照 JavaScript 的块级变量与 PHP foreach 的变量行为，解释跨语言改写时可能出现的意外。

```python
n = 99
squares = [n * n for n in range(3)]
print(squares, n)

for i in range(2):
    pass
print(i)
```

验收：能说明 Python 3 推导式迭代变量有独立作用域，而普通 for 循环不会创建新的块级作用域；代码若依赖循环后的变量，应显式赋值并考虑可读性。
