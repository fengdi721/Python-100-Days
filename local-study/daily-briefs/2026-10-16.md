## 5–10 分钟面试热身

先预测输出。Python 的 `in` 对字典检查什么？对比 PHP 中 `array_key_exists` / `in_array`，以及 JavaScript 中 `in` 会检查原型链、`Object.hasOwn` 只检查自有属性的区别。

```python
profile = {"language": "Python"}
print("language" in profile)
print("Python" in profile)
print("Python" in profile.values())
```

验收：能区分字典键成员判断与值成员判断，并避免把 JavaScript 的 `in` 语义直接套用到 Python 字典。
