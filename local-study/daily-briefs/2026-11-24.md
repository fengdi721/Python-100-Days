## 5–10 分钟面试热身

先预测创建视图后新增键，最终会输出什么：

```python
record = {"id": 17}
keys = record.keys()
record["status"] = "ready"
print(list(keys))
```

解释 `dict.keys()` 返回的是动态视图，因此会反映字典后续的键变化；它不是创建时的列表快照。对照 JavaScript 的 `Object.keys(record)` 返回数组，以及 PHP `array_keys($record)` 得到的数组；再说明遍历字典时增删键可能导致运行时错误或逻辑问题。
