## 5–10 分钟面试热身

先预测四行输出。列表和字符串的 += 分别是原地修改还是创建新值？为什么结果不同？联系 PHP 和 JavaScript 的字符串连接，说明仅凭赋值运算符长得相同，不能推断它们会以相同方式处理对象。

```python
items = [1, 2]
items_alias = items
items += [3]
print(items is items_alias, items_alias)

text = "py"
text_alias = text
text += "thon"
print(text is text_alias, text_alias, text)
```

验收：能说明 list 的 += 通常原地扩展对象，因此别名也看到新元素；str 不可变，+= 产生新字符串并让 text 重新绑定，text_alias 仍指向旧字符串。
