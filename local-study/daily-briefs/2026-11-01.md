## 5–10 分钟面试热身

先预测两次调用各自的输出。循环的 else 为什么在第一种输入中执行、第二种输入中不执行？continue 会阻止 else 吗？对照 PHP/JavaScript，写出不使用循环 else 时需要怎样的标志变量。

```python
def report_even_only(numbers):
    for number in numbers:
        if number % 2:
            print("found odd:", number)
            break
    else:
        print("no odd number")

report_even_only([2, 4, 6])
report_even_only([2, 3, 4])
```

验收：能说明循环 else 在循环正常耗尽且没有执行 break 时运行；continue 不会跳过它。理解该语法后，按团队可读性约定决定是否采用，必要时用显式 found 标志表达。
