## 5–10 分钟面试热身

先预测两次解包得到什么。为什么 `name, role = person` 得到的是键，而 JavaScript 的对象解构通常取得属性值？在 Python 中怎样明确地解包字典的值？

```python
person = {"name": "Ada", "role": "engineer"}
name, role = person
print(name, role)

name, role = person.values()
print(name, role)
```

验收：能说明字典迭代默认遍历键；若要遍历值或键值对，应显式使用 `.values()` 或 `.items()`，不要把两种语言的解构语义混为一谈。
