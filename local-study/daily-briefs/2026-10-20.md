## 5–10 分钟面试热身

先预测结果。Python 的 `len(str)`、Node.js 的 `string.length` 和 PHP 的 `strlen()` 分别计算什么？为什么“用户看到的字符数”还可能不同？

```python
samples = {"emoji": "😀", "combining accent": "e\u0301"}
for label, text in samples.items():
    utf16_units = len(text.encode("utf-16-le")) // 2
    utf8_bytes = len(text.encode("utf-8"))
    print(label, len(text), utf16_units, utf8_bytes)
```

验收：能说明 Python `len(str)` 计 Unicode 码点、JavaScript `.length` 计 UTF-16 代码单元、PHP `strlen()` 计字节；这些都不等同于字素簇（用户感知字符）的数量。
