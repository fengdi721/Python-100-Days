## 5–10 分钟面试热身

先预测两次调用分别打印什么，再解释原因：

```python
def add_tag(tag, tags=[]):
    tags.append(tag)
    return tags

print(add_tag("python"))
print(add_tag("php"))
```

说明为什么这个列表会在函数定义时创建并被后续调用共享。再写出 `None` 作为默认值、在函数体内创建新列表的安全版本，并说明 Node.js 默认参数表达式是在每次调用缺少参数时求值。
