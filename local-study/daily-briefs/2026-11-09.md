## 5–10 分钟面试热身

预测两个长度。一个非基本平面字符在 Python 字符串中通常占几个 Unicode 码点？为什么 JavaScript 的字符串 length、PHP 的 strlen 与 mb_strlen 可能给出不同数字？提醒：码点数也不一定等于用户看到的字形数量。

```python
symbol = "😀"
print(len(symbol))
print(len(symbol.encode("utf-8")))
```

验收：能说明 Python 的 len(str) 统计 Unicode 码点，UTF-8 编码后的长度统计字节；JavaScript length 对该字符按 UTF-16 码元计数，PHP strlen 按字节计数，而 mb_strlen 可按字符计数。复杂 emoji 序列可能由多个码点组成。
