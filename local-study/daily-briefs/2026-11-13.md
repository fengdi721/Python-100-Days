## 5–10 分钟面试热身

先预测两行结果。为什么 NaN 与自身比较也不相等？为什么 `x is x` 即使为真也不是 NaN 判断方法？对照 JavaScript 的 Number.isNaN，并说明验证 API 数字输入时应该先如何识别 NaN。

```python
import math
value = float("nan")
print(value == value)
print(math.isnan(value), bool(value))
```

验收：能说明 IEEE 浮点 NaN 的比较语义使 `value == value` 为假；用 math.isnan 检测，不能用相等或身份判断。NaN 在 Python 中仍是 truthy，因此条件判断也不能代替数值校验。
