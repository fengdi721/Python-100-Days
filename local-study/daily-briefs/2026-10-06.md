## 5–10 分钟面试热身

先不执行代码，写出结果，再运行。分别指出 PHP 中字符串 `"0"`、JavaScript 中空数组和空对象，与 Python 的真值判断有哪些容易混淆的地方。

```python
values = ["0", [], {}, 0, None]
print([bool(value) for value in values])
print("0" or "fallback")
print([] or "fallback")
```

最后用一句话解释：Python 的 `or` 返回的是布尔值，还是被选中的操作数？
