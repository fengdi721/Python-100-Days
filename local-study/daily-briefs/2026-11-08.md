## 5–10 分钟面试热身

先预测 `timeout` 和 `retries` 的值。Python 字典展开遇到重复键时由哪一边获胜？这和 JavaScript 对象展开、PHP array_merge 用于配置覆盖时有什么相似处？`{**defaults, **env}` 是否会修改 defaults？

```python
defaults = {"timeout": 5, "retries": 2}
env = {"timeout": 10}
config = {**defaults, **env}
print(config)
print(defaults)
```

验收：能说明从左到右展开，后出现的同名键覆盖先前值；该字面量创建新的浅层字典，嵌套值仍可能共享引用。
