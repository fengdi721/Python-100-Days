## 5–10 分钟面试热身

先预测输出，并说明 `n` 最后指向什么：

```python
n = "outer"
squares = [n * n for n in [1, 2, 3]]
print(squares, n)
```

解释为什么推导式中的 `n` 不会覆盖外层名称。比较 PHP `foreach` 变量在循环后仍可访问的常见行为，以及 JavaScript 使用 `let` 时的块级作用域；再预测把推导式改成普通 `for n in ...` 循环后会发生什么。
