## 5–10 分钟面试热身

先预测四组表达式的结果，再解释每个名称指向哪个对象。浅拷贝为什么会让 `a == c` 为真、但 `a is c` 为假？对照 JavaScript 的数组引用语义，并说明 PHP 数组赋值对你理解 Python 有何不同。

```python
a = [1, 2]
b = a
c = a[:]

print(a == b, a is b)
print(a == c, a is c)
b.append(3)
print(a, c)
```

验收：能区分值相等（`==`）与对象身份（`is`），指出 `b` 与 `a` 是同一列表，而 `c` 是新的浅拷贝；解释追加元素对两个变量的影响。
