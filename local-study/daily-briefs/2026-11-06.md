## 5–10 分钟面试热身

先预测输出。为什么两次 get 都会得到 None，但键是否存在的检查结果不同？如何在 Python 中区分“缺少键”和“值就是 None”？对照 PHP 的 isset 与 array_key_exists，以及 JavaScript 对 null 和 undefined 的区分。

```python
record = {"display_name": None}
print(record.get("display_name"), record.get("email"))
print("display_name" in record, "email" in record)

missing = object()
value = record.get("email", missing)
print(value is missing)
```

验收：能说明 dict.get 默认返回 None，因而不能仅凭返回值区分键缺失与显式 None；使用 in 或唯一哨兵对象可以保留这一区别。
