## 5–10 分钟面试热身

先预测两次打印的内容及 `first is second` 的结果。为什么两次调用会共享列表？对比 Node.js 中默认参数表达式按调用求值的行为，并口述如何在 Python 中避免这个问题。

```python
def add_tag(tag, tags=[]):
    tags.append(tag)
    return tags

first = add_tag("PHP")
second = add_tag("Node.js")
print(first, second, first is second)
```

验收：能解释 Python 函数默认参数在定义时求值，因此可变默认对象会跨调用共享；常见做法是用 `None` 作哨兵，并在函数体内新建列表。
