## 5–10 分钟面试热身

先预测两行输出。为什么两个变量别名下，列表与字符串的 `+=` 会呈现不同结果？对比 JavaScript 中对数组/字符串使用 `+=` 时的行为，再解释 Python 是何时修改对象、何时创建新对象并重新绑定名称。

```python
items = [1]
alias = items
items += [2]

text = "py"
text_alias = text
text += "thon"

print(alias, items)
print(text_alias, text)
```

验收：能分别解释对象别名、原地修改与名称重新绑定；避免笼统说 Python “按引用传参”。
