## 5–10 分钟面试热身

先预测输出。为什么 `True`、`1` 和 `1.0` 在 Python 中相等且哈希相同？因此它们放进集合或作为字典键时会怎样？对照 JavaScript `Map` 中 `true` 与 `1` 是不同键；再想想 PHP 数组键的类型转换。

```python
values = [True, 1, 1.0]
print(True == 1, 1 == 1.0)
print(len(set(values)))
print({True: "bool", 1: "int", 1.0: "float"})
```

验收：能说明字典/集合按相等与哈希判断键是否相同，因此后续相等键会覆盖同一条目；设计跨语言数据模型时，不依赖 `bool` 和数字键之间的隐式区分。
