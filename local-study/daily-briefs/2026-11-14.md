## 5–10 分钟面试热身

逐条判断调用是否合法，并解释函数签名中的斜杠和单独星号分别约束什么。和 PHP 的命名参数、JavaScript 常用 options 对象相比，这种签名能为 API 带来什么约束？

```python
def connect(host, /, *, timeout):
    return host, timeout

print(connect("api.example", timeout=3))
# 以下两种调用各会怎样？
# connect(host="api.example", timeout=3)
# connect("api.example", 3)
```

验收：能说明 host 是 positional-only，不能用关键字传入；timeout 是 keyword-only，必须用关键字传入。调用限制可稳定公共接口，避免参数名称变化影响调用方，也能减少位置参数顺序误用。
