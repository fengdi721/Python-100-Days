## 5–10 分钟面试热身

先预测输出。`all` 和 `any` 会在空 iterable 上返回什么？这与 JavaScript 的 `[].every(...)` 和 `[].some(...)` 有何对应关系？如果 API 要求“至少一项且全部有效”，为什么只检查 all(items) 不够？

```python
print(all([]), any([]))

flags = [True, True, False]
print(all(flags), any(flags))
```

验收：能解释 all 检查没有反例时为空集也为真，any 需要至少一个真值；要求非空时先显式检查集合长度，再检查 all。all/any 会短路，生成器输入也可以逐项惰性求值。
