## 5–10 分钟面试热身

先预测输出以及两个 `is` 判断的结果：

```python
items = [1]
items_alias = items
items += [2]
print(items, items_alias, items is items_alias)

pair = (1,)
pair_alias = pair
pair += (2,)
print(pair, pair_alias, pair is pair_alias)
```

说明列表的增量拼接会原地修改对象，而元组不可变，增量拼接会创建新元组并重新绑定名称。比较 JavaScript 用 `push` 修改数组，以及 PHP 用 `$array[] = $value` 追加元素；不要假设不同语言的 `+=` 语义相同。
