## 5–10 分钟面试热身

先预测两个比较结果。为什么 0.1 与 0.2 的二进制浮点近似相加后不一定精确等于 0.3？为什么 math.isclose 比直接用 == 更适合比较测量值？对照 PHP 和 Node.js，说明这并非 Python 独有。

```python
import math
total = 0.1 + 0.2
print(total == 0.3)
print(math.isclose(total, 0.3))
```

验收：能说明常见二进制浮点格式无法精确表示许多十进制分数，比较实数结果应按业务尺度选择容差；金额场景优先采用 Decimal 或整数最小单位。
