## 5–10 分钟面试热身

先预测两行输出以及 `range` 是否已被“消耗”：

```python
numbers = range(1, 4)
print(list(numbers))
print(list(numbers))
```

解释 Python `range(start, stop)` 包含 start、不包含 stop，而且它是可重复遍历的序列对象，不是一次性迭代器。对照 PHP `range(1, 4)` 两端都包含，以及 Node.js 常见的 `i < stop` 循环边界。
