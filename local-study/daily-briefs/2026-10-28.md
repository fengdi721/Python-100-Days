## 5–10 分钟面试热身

先预测结果，再说明 `//` 与 `%` 满足的关系 `a == (a // b) * b + (a % b)`。为什么 `-7 // 3` 得到 `-3`，而 PHP 的 `intdiv(-7, 3)` 和 JavaScript 的 `Math.trunc(-7 / 3)` 得到 `-2`？

```python
for a, b in ((7, 3), (-7, 3), (7, -3), (-7, -3)):
    print(a, b, a // b, a % b)
```

验收：能解释 Python 整除向负无穷取整，且余数与除数同号（或为零）；处理分页、索引或时间计算时，会先确认目标语言的除法约定。
