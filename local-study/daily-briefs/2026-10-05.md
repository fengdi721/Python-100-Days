## 5–10 分钟面试热身

先预测所有表达式的结果，再解释 `==` 与 `is` 各比较什么；对照 JavaScript 中 `[] === []` 的行为。不要用小整数或字符串常量做身份判断示例，因为解释器可能复用它们。

```python
left = []
right = []
alias = left
print(left == right, left is right)
print(left == alias, left is alias)
left.append(1)
print(left == right, left is alias)
```

验收：能在不依赖对象地址的前提下解释每行，并说明 `None` 通常用 `is`，内容比较通常用 `==`。
