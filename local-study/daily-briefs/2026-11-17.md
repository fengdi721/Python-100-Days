## 5–10 分钟面试热身

先预测每个表达式的值与类型：

```python
fallback = [] or {"source": "default"}
selected = "python" and 3
print(fallback, type(fallback).__name__)
print(selected, type(selected).__name__)
```

解释为什么 `or` 和 `and` 在 Python 中返回操作数，而不一定返回 `bool`；再说明空列表在 Python 中是假值、在 JavaScript 中却是真值。补充 PHP 的 `||` 通常产生布尔结果。
