## 5–10 分钟面试热身

先预测列表和 `result` 的内容及类型：

```python
values = [3, 1, 2]
result = values.sort()
print(values)
print(result)
```

解释 `list.sort()` 会原地排序并返回 `None`，适合需要修改原列表的场景；若要得到新的排序列表，用 `sorted(values)`。对照 JavaScript `Array.sort()` 会原地排序并返回数组本身，以及 PHP `sort()` 原地修改数组并返回布尔值。
