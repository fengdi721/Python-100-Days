## 5–10 分钟面试热身

先预测普通 zip 会产生多少对。再运行 strict=True 版本：长度不同时会发生什么？如果你在 PHP/Node.js 中手动按索引配对两个来自不同 API 的数组，应该怎样避免静默截断或错配？

```python
ids = [101, 102, 103]
names = ["Ada", "Lin"]
print(list(zip(ids, names)))

try:
    print(list(zip(ids, names, strict=True)))
except ValueError:
    print("length mismatch")
```

验收：能说明默认 zip 在最短输入耗尽时停止；strict=True（Python 3.10+）会在长度不一致时抛 ValueError，适合不允许数据静默丢失的场景。
