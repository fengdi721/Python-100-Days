## 5–10 分钟面试热身

先预测循环输出。enumerate 的 start 参数会不会跳过列表元素？它返回整个列表，还是逐步产生“索引、值”对？将它与 JavaScript 的 entries() 和 PHP foreach 的键值遍历对照，并说明为什么不应手动维护索引计数器。

```python
frameworks = ["Django", "FastAPI", "Flask"]
for position, name in enumerate(frameworks, start=1):
    print(position, name)
```

验收：能说明 enumerate 为迭代过程产生带索引的二元组，start 只设置起始计数值、不改变序列遍历；它支持惰性迭代，适合避免 range(len(items)) 与手动计数。
