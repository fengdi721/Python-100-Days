## 5–10 分钟面试热身

先不运行，预测输出和返回值的实际类型：

```python
def repeat(value: str) -> str:
    return value * 2

result = repeat(7)
print(result, type(result).__name__)
```

解释为什么 Python 会接受这个调用，以及类型标注能帮助哪些工具或读者。对照 TypeScript 的静态检查和 PHP 的类型声明，说明不能仅凭 `str` 注解认定 Python 解释器会在运行时验证参数或返回值。
