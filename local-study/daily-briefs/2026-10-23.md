## 5–10 分钟面试热身

先预测两行输出。`list.sort()` 会不会修改原列表、返回什么？怎样得到排序后的新列表并保留原顺序？对比 PHP 与 JavaScript 的排序 API。

```python
tags = ["python", "PHP", "Node.js"]
result = tags.sort(key=str.casefold)
print(tags, result)

original = ["python", "PHP", "Node.js"]
sorted_copy = sorted(original, key=str.casefold)
print(original, sorted_copy)
```

验收：能说明 `list.sort()` 原地排序并返回 `None`，`sorted()` 返回新列表；对比其他语言时，也明确指出其 API 是否原地修改以及返回值是什么。
