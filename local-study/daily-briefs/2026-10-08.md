## 5–10 分钟面试热身

先预测下面三行的输出。为什么 Python 中 `bool` 会通过 `isinstance(..., int)`？如果接口要求“整数，但不接受布尔值”，你会如何写验证？对照 JavaScript 的 `typeof true`、`true === 1`。

```python
values = [True, 1, 1.0]
print([isinstance(value, int) for value in values])
print([type(value) is int for value in values])
print(len(set(values)))
```

验收：能区分继承/类型检查、值相等与哈希集合去重；说清 `isinstance` 与精确类型检查的适用场景。
