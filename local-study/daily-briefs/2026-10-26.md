## 5–10 分钟面试热身

先预测每行的结果。为什么 Python 把空列表和空字典判为假、却把字符串 `"0"` 判为真？对照 JavaScript（空数组、空对象为真）和 PHP（字符串 `"0"` 为假），说明跨语言迁移时直接照搬条件判断可能产生什么 bug。

```python
values = [[], {}, "", "0", 0, None]
print([bool(value) for value in values])
```

验收：能说清 Python 的空容器、空字符串、数值零和 `None` 为假，而非空字符串（包括 `"0"`）为真；在 API 输入校验中能明确写出预期条件，而不依赖模糊的真假判断。
