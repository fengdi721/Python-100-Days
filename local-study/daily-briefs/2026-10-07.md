## 5–10 分钟面试热身

不执行代码，先预测 `records` 最终的内容。解释函数里的 `append` 和 `records = ...` 分别改变了什么；用一句话说明这为什么不能简单称为“传引用”。再比较 JavaScript 对对象参数的行为。

```python
def update(records):
    records.append("Node.js")
    records = ["new list"]


records = ["PHP"]
update(records)
print(records)
```

验收：能区分修改共享对象与把局部名称重新绑定，并说明调用方为什么仍看到追加项。
