# 面试回答要点：先口述，再核对

建议答题结构：一句结论 → 最小例子 → 适用边界 → 实践取舍。每道60–90秒；不能只背定义。

| 高频问题 | 回答应包含的要点 |
|---|---|
| 赋值与传参 | 名称绑定到对象；修改共享对象可被调用方看到，重新绑定局部名称不能改变调用方绑定 |
| is / == | 身份与相等；==可定制；None用is；不能依赖字符串/整数驻留 |
| truthiness | 空容器/零/None为假；非空'0'为真；and/or返回操作数且短路 |
| 默认参数 | 定义时求值一次；可变默认值可被后续调用共享；None或独立哨兵 |
| 浅/深拷贝 | 浅拷贝只建外层；deepcopy递归并维护备忘；资源对象不一定可复制 |
| dict / set | 键需可哈希；平均查找O(1)不是最坏保证；dict保留插入顺序但不自动按值排序 |
| == / hash | 相等对象必须有相同hash，反向不成立；作为键时不要改变参与hash/相等的状态 |
| 闭包 | 自由变量按绑定访问，可发生晚绑定；nonlocal修改外层绑定；默认值可冻结当前引用 |
| 装饰器 | 函数定义后包装；@a @b等于a(b(f))；wraps保留元信息，不能解决所有签名/类型问题 |
| iterable / iterator | 前者可取得迭代器，后者有next状态且iter通常返回自己；迭代器可被消耗 |
| 生成器 | yield暂停并保存状态，惰性执行；错误可能推迟到迭代；返回值通过StopIteration携带 |
| with | 协议管理进入/退出；__exit__真值可抑制异常；清理必须考虑异常路径 |
| 类型标注 | 通常不强制运行时校验；Any弱化检查，object需缩窄；cast不做运行时转换 |
| dataclass | 自动生成常见方法但业务校验仍需实现；default_factory防共享；frozen不是深度冻结 |
| super / MRO | super沿MRO寻找后继，不是固定某个父类；协作多继承要求兼容签名和调用协议 |
| 描述符 | 数据描述符优先于实例字典，实例字典又优先于非数据描述符；property是常见应用 |
| del / GC | del删除引用/绑定；CPython常用引用计数加循环GC；不能把析构时机当跨实现契约 |
| slots | 限制/改变实例属性存储方式，可能节省内存；不自动使对象不可变或线程安全 |
| GIL | 有GIL的CPython限制同一解释器里同时执行Python代码的线程；I/O仍可重叠；原生扩展可能释放GIL |
| free-threading | 是特定构建/运行配置，不能概括为所有Python都无GIL；仍要同步共享状态，扩展兼容性需确认 |
| 线程/进程/协程 | I/O可用线程/协程；CPU纯Python常考虑进程或合适构建；进程有启动/序列化成本，协程靠合作调度 |
| coroutine启动 | 调用async def返回coroutine，需await或调度才执行；JS async函数调用通常立即开始执行到首个await |
| TaskGroup | 管理子任务生命周期；非取消异常通常取消兄弟任务并汇总异常；与gather默认行为不同 |
| 取消/超时 | 取消在可响应点注入异常；finally清理；一般不要吞CancelledError；超时转换异常有上下文边界 |
| 背压/限流 | Queue上限控制积压，Semaphore控制并发；QPS需时间维度规则；三者不可混同 |
| 锁与竞态 | 业务读改写不是一个原子操作；GIL不保证业务不变量；锁范围过大影响并发且可能死锁 |
| mock | 在被测代码查找名称的位置patch；注入依赖更直观；不以mock内部调用代替真实行为断言 |
| 测试 | 正常、边界、错误与资源清理；单元快速隔离、集成检查协作；覆盖率不能证明断言有效 |
| SQL事务 | 批次原子性与回滚；参数化处理值；连接关闭与事务管理是不同生命周期 |
| 性能 | 先profile找热点，再比较相同语义；报告输入/环境/多次数据；算法复杂度往往比微优化重要 |
| 打包 | 导入路径、包发现、依赖与入口须在干净目录验证；venv隔离包，不等于容器或系统隔离 |
| HTTP重试 | 明确超时/重试预算/退避；写操作需业务幂等策略；无法把所有异常都当可重试故障 |
| 元类 | 定制类的创建；许多注册/验证需求用__init_subclass__或类装饰器足够；选择复杂机制要有必要性 |
| 版本差异 | 回答注明Python/实现版本；3.14注解规则与t-string有变化；新版本支持不等于项目已启用 |

这些是简明自检线索，不是完整标准答案。涉及具体语义和版本时回到 [语言参考](https://docs.python.org/3.14/reference/)、[数据模型](https://docs.python.org/3.14/reference/datamodel.html)、[asyncio](https://docs.python.org/3.14/library/asyncio-task.html) 和 [free-threading](https://docs.python.org/3.14/howto/free-threading-python.html) 验证。
