# Day 05 · 函数签名与参数传递

第 1 周 · 每天 60–90 分钟 · [返回目录](../DAILY_INDEX.md)

## 今日知识

def/return、默认参数、位置专用 /、仅关键字 *、*args/**kwargs、参数解包、文档字符串。

## 主练习（约30–40分钟）

实现 merge_config(base, /, *, overrides=None)：返回新字典，overrides 优先；仅做顶层合并；再修复 append_tag(tag, tags=[]) 的共享默认参数问题。

## 验收标准

连续调用不互相污染；base= 关键字调用应 TypeError；overrides 不被修改；明确嵌套对象仍共享。

除题目另有规定，写出正常、空输入、边界/非法输入的测试。说明你的接口约定，不要为了通过一个样例硬编码。

## 短练习 / 易错点（约10–15分钟）

分别执行 def change(x): x.append(1) 与 def change(x): x=[1]，观察调用方列表；预测 *a,b=[1,2,3] 的值。

## 面试口述（约10分钟）

Python 参数传递如何用名称绑定解释？默认参数何时求值？
